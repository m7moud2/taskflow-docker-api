TaskFlow Docker API

Production-ready REST API containerized with Docker, PostgreSQL, Redis, and Nginx reverse proxying.

Reverse Proxy
Nginx 1.25
Database
PostgreSQL 16
Cache & Limiter
Redis 7
Runtime
Node.js TS

Available API Endpoints

  • GET /api/v1/health - System Healthcheck & Metrics
  • GET /api/v1/tasks - Fetch all tasks (Cached in Redis)
  • POST /api/v1/tasks - Create a new task
  • PUT /api/v1/tasks/:id - Update an existing task
  • DELETE /api/v1/tasks/:id - Remove a task
